КАК ЗАПУСТИТЬ DATING BOT (Windows, 5 минут)
==========================================

1. УСТАНОВИ PYTHON
   Скачай Python 3.12 с python.org (Windows 64-bit).
   При установке поставь галочку "Add python.exe to PATH".
   Проверка: открой PowerShell и введи  python --version
   Должно показать Python 3.12.x (а не просто "Python").

2. СОЗДАЙ БОТА
   В Telegram открой @BotFather -> /newbot -> придумай имя.
   Скопируй токен. Свой ID узнай у @userinfobot.

3. НАСТРОЙ .env
   Скопируй файл .env.example в .env (просто скопируй и переименуй).
   Открой .env блокнотом и впиши:
     BOT_TOKEN=токен_от_BotFather
     ADMIN_IDS=твой_ID
     ADMIN_PASSWORD=356872
   Остальное не трогай.

4. ЗАПУСТИ
   Двойной клик по start.bat в папке бота.
   Первый запуск дольше: создастся venv и поставятся библиотеки.
   В конце увидишь: Dating Bot запущен.
   Остановка: Ctrl+C или закрыть окно.

5. ПРОВЕРЬ
   В Telegram открой своего бота -> /start -> создай анкету.
   Админка: /admin356872 -> пароль 356872.

ЧАСТЫЕ ОШИБКИ
- "Python ne nayden" — Python не в PATH, переустанови с галочкой.
- Окно сразу закрывается — запускай через start.bat, там пауза и текст ошибки.
- ModuleNotFoundError — не встали библиотеки, удали папку venv и запусти снова.
- Два бота на одном токене одновременно НЕ работают (Telegram отдаёт
  обновления только одному). На втором ПК или останови первого, или
  создай второго бота через @BotFather с другим токеном.

ЧТО НЕ КОПИРОВАТЬ НА ДРУГОЙ ПК
- папку venv (создастся сама)
- файл data/bot.db (база создастся сама)
- файл .env с чужим токеном (сделай свой по шагу 3)
